# AI 应用小团队交付闭环：第二轮实现与验证

本轮继续聚焦交付知识助手和业务工作流的小团队。交付单元是应用版本：绑定资源、真实测试、保存回归用例、后台运行、校验发布门禁、调用 API、查看请求及执行证据、回滚。

差异化落实在可复查的交付过程：版本关联测试证据，用例和源配置变化后重新校验；知识内容实时变化时，不将旧评测冒充当前证明。界面沿用现有石墨与青绿色体系，以表单、状态、版本记录和条目列表组织操作，支持四种主题和移动端。

## 已落地

| 能力 | 当前行为 |
| --- | --- |
| 应用回归 | 服务端持久化测试集、用例与批次；九类确定性断言；JSON 导入导出；保存当前输入或真实请求为用例；分页历史及版本对比。 |
| 真实后台执行 | Celery 独立批次、冻结草稿或指定历史版本、启动幂等、排队失联与总超时、共享调用容量；真实 Worker 取消并停止后续用例，已发生的外部副作用不能撤回。页面离开不伪装成任务停止。 |
| 发布门禁 | 可选指定测试集，必须完整通过当前用例修订、配置与知识内容；保留原有单次成功证明。发布记录保留不可变的评测关联。 |
| 配置检查 | 分别检查草稿和线上版本的资源、实际文档与分块、索引和服务配置；不发送上游请求，不声称连接已验证。 |
| 执行追踪 | 应用请求内读取关联主流程的真实状态、节点和时间，失败可重试与刷新；隐藏工作流定义、凭据、日志和节点载荷不因此开放。 |
| 知识库往返 | 暂存应用名称、说明和空间，创建知识库后回到原草稿并核验新资源；处理取消、失败、身份变化、过期、权限撤销和数字团队 ID 回显。 |
| 团队知识与权限 | 默认存储按所有者和团队隔离；显式存储与集合同空间；离队或团队停用后，原创建者不能继续读写；Viewer 保留查询，成员及管理员按当前角色操作。项目记忆从可信站点继承空间。 |
| 模型管理与评测 | 真实供应商协议探测、密钥脱敏与空密钥编辑保留、目录默认模型权限及互斥；已登记的真实模型和标注数据产生实际指标，保留零分和无法计算状态。 |
| 本地服务 | 独立管理 API、Worker、Beat，核对进程归属和实际就绪；不清空队列、不全局结束无关进程、不自动迁移业务数据库。 |

训练到评测保留实际训练的特征列、标签列和归一化参数；旧产物仅能从有权限的原训练数据恢复预处理，不使用测试集拟合。模型缺失、非法文件、未授权资源、空数据或不支持的指标均明确失败，已移除随机评测成功。

旧模型部署节点原先返回并不存在的地址或哈希名称。当前已移除假成功，前置检查和界面明确标记适配器未接入，原四个平台配置保留。**应用中心的版本发布和 API 调用已经实现；独立模型服务的本地、SageMaker、LambdaGPU、Triton 适配器仍未实现。不能把整个历史功能目录称为全部完成。**

## 验证记录

最终验证使用独立数据库、消息队列和浏览器 Profile，未连接业务数据库或触发 GPU 长训练。普通测试 Profile 显式使用内存 broker/result；独立验收 Worker 使用受守卫保护的 filesystem 队列，验证 eager=False 的真实进程执行。

业务数据没有自动迁移；部署时应按项目文档应用已提供的迁移并启动真实 Worker，定时功能还需要 Beat。既有跨空间知识绑定不自动迁移，有文档时仍禁止直接切换存储，需显式新建并导入。未签名目录包用于本地验证，未执行远端部署、镜像推送或安装器发布。宿主 GPU 环境、用户原有改动及声明文件保留。

知识应用还需要配置平台回答服务（`RAG_CHAT_MODEL`、`RAG_CHAT_API_KEY`、`RAG_CHAT_BASE_URL` 或对应受支持的服务配置）；个人模型页的密钥不自动用于平台知识问答。语义检索需要实际嵌入服务、所选向量后端驱动和服务，并在索引配置变化后重新处理文档；关键词检索不要求嵌入服务。正式部署需持久保存数据库、上传文件、模型产物、向量数据及配置的备份目录，并通过真实输入测试确认外部连接。
