# Markdown 格式自检对照表（comp_cumcm 工作流参考）

> 此文件仅作为 docx-format-check 步骤的**自检对照参考**，不参与渲染、不当模板。
> 具体格式要求由 docx-export 渲染引擎按 `competition_zh.json` 应用。

**核心规范摘要**：数学建模竞赛中文论文（对标 cumcmthesis.cls）：A4 纸 25mm 边距，正文宋体小四 12pt 1.5 倍行距，章节用「一、二、三、」中文序号。

## 一、页面与正文规范

- 纸张：A4
- 页边距：上 2.5 cm / 下 2.5 cm / 左 2.5 cm / 右 2.5 cm
- 正文字号：12 pt（中文小四号）
- 正文行距：1.5 倍
- 首行缩进：2 个汉字字符宽度
- 中文正文字体：SimSun（宋体）
- 中文标题字体：SimHei（黑体）
- 西文字体：Times New Roman

## 二、Markdown 标题层级与渲染映射

| Markdown 写法 | 渲染字号(pt) | 加粗 | 对齐 | 用途 |
|--------------|------------|------|------|------|
| `# 论文题目` | 18 | 是 | center | 论文/报告题目（自动用 title 样式） |
| `## 摘要` | 14 | 是 | center | 摘要标题（引擎特殊路径） |
| `## 一、章节名` | 15 | 是 | center | 一级章节 |
| `### 1.1 小节名` | 14 | 是 | left | 二级小节 |
| `#### 1.1.1 子节名` | 12 | 是 | left | 三级子节（慎用） |

⛔ **关键铁律**（按引擎实际行为）：

1. **整篇论文 `#` 只用一次**（论文题目），所有正文章节从 `## ` 起步。
2. **`## 摘要` / `## Abstract` / `## Summary` 自动走特殊样式**（居中加粗）— 摘要标题必须正好是「摘要」/「Abstract」/「Summary」。
3. **`**关键词**：xxx` 是普通段落**（不是 heading），引擎自动用黑体加粗标签；冒号写在 `**` 外面。
4. **章节用 `#` 开头**，禁止 `- 章节名`（list 项 → 渲染成 "•"）。

## 三、推荐章节骨架（仅供结构对照，不要照搬具体名称）

按 `comp_cumcm` 工作流的特点，建议骨架如下：

```
# 论文题目
## 摘要
**关键词**：xxx, yyy, zzz
## 一、问题重述（含问题背景与待解决的问题）
## 二、问题分析
## 三、模型假设与符号说明
### 3.1 模型假设
### 3.2 符号说明
## 四、模型建立与求解
### 4.1 问题一：xxx 模型
### 4.2 问题二：xxx 模型
## 五、模型评价（优缺点 / 推广 / 灵敏度）
## 参考文献
## 附录（可选）
```

## 四、题注与公式编号

- 图题：`![图 1：图题描述](figures/fig_xxx.png)` — **题注独占行**，不要 `- ` 前缀
- 表题：`**表 1 表题**` 独占一行，紧接 Markdown 三线表
- 块公式编号与公式**同一行**：`$$ ... \tag{1} $$` 或行内编号，禁止独立的 `- (1)` 列表行

## 五、加粗规则

- 结构化标签：`**关键词**：`、`**假设 N**：`、`**定理 1**`（定理名加粗，证明正文不加粗）
- 禁止整段/整节滥用加粗

## 六、表格规范

- 顶线 1.5 pt / 表头线 0.75 pt / 底线 1.5 pt
- 表内字号 10.5 pt（小五号）
- ⛔ 用纯 Markdown 表格 `| ... |`，禁止 LaTeX `\begin{tabular}`
- 数据来源优先 `figures/TABLE_*.md`（paper-figure 步骤已生成）

## 七、图片规范

- 必须 `.png`，不能 `.pdf`
- 最大宽度约 14 cm，居中

## 八、参考文献规范

- 上标引用：`[1]` `[2,3]` `[4-6]` — 不要用 `\cite{}`
- 悬挂缩进 0.74 cm，字号 10.5 pt

## 九、关键词标签

- 标签字号 12 pt，字体 SimHei（黑体）

## 自检清单

1. ☐ 所有章节标题用 `#` 开头，没有 `- xxx` 伪标题
2. ☐ 题注独占行，没有 `- ` 前缀
3. ☐ 块公式编号与公式同行
4. ☐ Markdown 表格分隔行存在，每行列数一致
5. ☐ 图片用 `.png`，不引用 `.pdf`
6. ☐ 章节层级合理（H1 唯一，H2/H3/H4 按推荐骨架排布）
7. ☐ 加粗只用在结构化标签
8. ☐ 没有 LaTeX 残留（`\begin{}` `\section{}` `\cite{}`）
