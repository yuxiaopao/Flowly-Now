## 1. 系统简介

### 1.1 系统概述

e-Flowly 是一个企业级 AI Agent 工作流编排平台，提供以下核心功能：

- **可视化工作流编辑器**：基于拖拽方式构建 AI 工作流
- **自然语言生成**：通过自然语言描述自动生成工作流
- **多模态 AI 节点**：支持 LLM、图像生成、视频生成、语音处理等
- **RAG 知识库**：向量检索增强生成
- **多租户协作**：支持团队管理和权限控制

### 1.2 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                        用户界面层                             │
│         Web 浏览器 / 移动端 / API 接口                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      后端服务层                              │
│   Django REST Framework + Channels (WebSocket)             │
└─────────────────────────────────────────────────────────────┘
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│     MySQL       │  │  PostgreSQL     │  │     Redis       │
│   业务数据        │  │  + pgvector    │  │  缓存/队列      │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

### 1.3 技术指标

| 指标名称 | 指标值 |
|----------|--------|
| 系统响应时间 | < 200ms |
| 最大并发用户数 | 1000+ |
| 工作流节点数量 | 无限制 |
| 支持的 AI 模型 | 20+ |
| 向量检索精度 | 95%+ |

## 2. 快速入门

### 2.1 登录系统

1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 点击"登录"按钮进入系统

### 2.2 创建第一个工作流

**方式一：可视化编辑**

1. 点击左侧菜单"工作流"
2. 点击"新建工作流"按钮
3. 在画布上拖拽节点到指定位置
4. 连接节点，设置节点属性
5. 点击"保存"按钮

**方式二：自然语言生成**

1. 点击左侧菜单"NL 创建"
2. 在输入框中描述需求，例如："帮我做一个客服机器人"
3. 系统自动生成工作流
4. 预览确认后点击"保存"

### 2.3 执行工作流

1. 打开已保存的工作流
2. 点击"执行"按钮
3. 填写输入参数
4. 查看执行结果

## 3. 工作流管理

### 3.1 工作流列表

工作流列表页面显示所有工作流，包括以下信息：

- 工作流名称
- 状态（草稿/已发布/已归档）
- 创建时间
- 执行次数
- 操作按钮

支持的功能：

- **搜索**：按名称搜索工作流
- **筛选**：按状态、分类筛选
- **排序**：按创建时间、执行次数排序

### 3.2 工作流编辑器

#### 3.2.1 节点类型

系统支持以下节点类型：

**基础节点**

| 节点类型 | 功能说明 |
|----------|----------|
| 开始节点 | 工作流入口，每个工作流有且仅有一个 |
| 结束节点 | 工作流终点，可以有多个 |
| 输入节点 | 定义工作流的输入参数 |
| 输出节点 | 定义工作流的输出格式 |

**逻辑节点**

| 节点类型 | 功能说明 |
|----------|----------|
| 条件节点 | 根据条件分支执行 |
| 分支选择 | 多分支选择 |
| 循环节点 | 循环执行一组节点 |
| 延时节点 | 延时执行 |

**AI 节点**

| 节点类型 | 功能说明 |
|----------|----------|
| LLM 节点 | 调用大语言模型 |
| 提示词节点 | 模板化提示词 |
| RAG 节点 | 知识检索增强 |

**工具节点**

| 节点类型 | 功能说明 |
|----------|----------|
| HTTP 请求 | 发送 HTTP 请求 |
| 代码执行 | 执行自定义代码 |
| 工具调用 | 调用预定义工具 |
| Webhook | 发送 Webhook 通知 |

**多媒体节点**

| 节点类型 | 功能说明 |
|----------|----------|
| 图像生成 | DALL-E、Stable Diffusion 等 |
| 视频生成 | SVD 等 |
| 语音生成 | TTS 等 |

#### 3.2.2 节点操作

- **添加节点**：从左侧节点面板拖拽到画布
- **删除节点**：选中节点后按 Delete 键或点击删除按钮
- **连接节点**：从节点输出拖拽到另一节点输入
- **配置节点**：双击节点打开配置面板

#### 3.2.3 节点配置

每个节点类型都有相应的配置项：

**LLM 节点配置**

```
模型选择：gpt-4 / gpt-3.5-turbo / llama3 / ...
提示词：输入提示词内容
温度：0.0 - 1.0
最大令牌数：1 - 128000
```

**条件节点配置**

```
条件表达式：field == "value"
分支标签：分支名称
```

**HTTP 请求节点配置**

```
请求方法：GET / POST / PUT / DELETE
请求地址：https://api.example.com
请求头：{"Authorization": "Bearer xxx"}
请求体：{"key": "value"}
```

### 3.3 版本管理

- **查看历史版本**：点击"版本历史"查看所有版本
- **版本对比**：选择两个版本进行对比
- **版本回滚**：选择历史版本进行回滚

### 3.4 执行管理

- **立即执行**：手动触发执行
- **定时执行**：设置定时任务
- **API 触发**：通过 API 接口触发
- **Webhook 触发**：接收外部 Webhook 触发

## 4. 自然语言生成工作流

### 4.1 功能概述

自然语言生成（NL to Workflow）允许用户通过自然语言描述需求，系统自动生成工作流。

### 4.2 使用流程

1. **输入需求**：在输入框中描述工作流需求

   ```
   示例：帮我做一个客服机器人，用户提问后自动回复
   ```

2. **AI 分析**：系统分析用户意图

3. **生成工作流**：系统生成符合需求的工作流

4. **预览确认**：预览生成的工作流

5. **修改确认**：可对工作流进行修改

6. **保存发布**：保存并发布工作流

### 4.3 支持的工作流类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 问答机器人 | 常见问答自动回复 | 客服 FAQ |
| 数据处理 | ETL、格式转换 | CSV 导出 |
| 翻译工作流 | 多语言翻译 | 中英互译 |
| 内容审核 | 文本/图像审核 | 评论过滤 |
| 文章生成 | 营销文案创作 | 产品描述 |
| 客服工作流 | 复杂客服流程 | 工单处理 |

### 4.4 多轮对话

支持多轮对话迭代优化工作流：

1. 第一轮：描述基本需求
2. 第二轮：添加更多细节
3. 第三轮：修改特定部分
4. 最终确认：保存工作流

### 4.5 流式输出

系统支持流式输出，实时显示生成进度：

```
正在分析需求...
正在选择工作流模板...
正在生成节点...
正在连接节点...
完成！
```

## 5. Agent 管理

### 5.1 Agent 概述

Agent 是具有特定能力的 AI 代理，可以执行特定任务。

### 5.2 创建 Agent

1. 点击"Agent"菜单
2. 点击"新建 Agent"按钮
3. 填写 Agent 基本信息
4. 选择 AI 模型
5. 配置系统提示词
6. 绑定工具和技能
7. 保存 Agent

### 5.3 Agent 配置

**基本信息**

```
名称：Agent 名称
描述：Agent 功能描述
模型：选择的 AI 模型
```

**提示词配置**

```
系统提示词：定义 Agent 的角色和能力
示例对话：提供示例对话
约束条件：Agent 需要遵循的规则
```

**工具绑定**

```
可用工具：Agent 可以调用的工具
工具参数：工具的默认参数
```

### 5.4 Agent 调试

提供在线调试功能：

1. 输入测试消息
2. 查看 Agent 响应
3. 检查中间过程
4. 调整配置优化效果

## 6. 知识库管理

### 6.1 RAG 架构

系统采用 RAG（检索增强生成）架构：

```
用户查询 → 向量化 → 相似度检索 → 上下文增强 → LLM 生成
```

### 6.2 创建知识库

1. 点击"知识库"菜单
2. 点击"新建知识库"按钮
3. 填写知识库信息
4. 配置向量存储
5. 上传文档
6. 开始索引

### 6.3 文档管理

**支持的文件格式**

- TXT
- PDF
- DOCX
- Markdown
- HTML

**文档处理**

- 自动分块
- 向量化存储
- 元数据提取

### 6.4 向量存储配置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 向量维度 | Embedding 向量维度 | 1536 |
| 分块大小 | 文档分块大小 | 1000 |
| 分块重叠 | 块间重叠字符数 | 200 |
| 相似度度量 | 余弦相似度/欧氏距离 | cosine |

### 6.5 检索测试

提供在线检索测试功能：

1. 输入查询内容
2. 执行检索
3. 查看检索结果
4. 调整检索参数优化效果
