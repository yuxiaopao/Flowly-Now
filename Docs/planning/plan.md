在工作流中的模型训练模块节点，我觉得应该是这样一个流程，
1.上传已标记好的数据集，如果没标记好，得有下拉框进行选择，
2.在标记数据集节点模块，这个节点的工序需要很多呀，需要框选哪一类标签方框，还需要有很多特征的提取，我不是很建议有帮客户去现给数据集打标记，费力还不准确，其实我们可以去给客户推荐几个数据集网站，让客户找到自己觉得好已标记的数据集来进行训练，
3.训练模型的节点也得注意，因为这个节点是需要去确定客户本地电脑是否有GPU，好给客户电脑推适合训练的环境配置，以便得出最好的pt权重文件，
4.最后再让客户说明，这个权重文件具体是用来做什么的，训练出来的类别包括哪几类，进而可以给客户搭建出一个前后端分离的可用网站来！这个网站只支持本地部署，如果要生产部署得由他自己去弄好配置文件，生成出来的代码文件，就生成在客户上传的空文件中！前提一定是空文件。
