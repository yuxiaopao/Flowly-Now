# 第 1 章　引言

## 1.1　项目设计需求

### 1.1.1　研究背景

随着大语言模型（LLM）技术的快速发展与广泛应用，AI Agent（人工智能代理）正逐步成为人工智能应用的主流形态。AI Agent 能够自主感知环境、做出决策并执行动作，在智能问答、自动化办公、数据分析、内容生成等众多场景中展现出巨大潜力。然而，构建一个完整的 AI Agent 应用往往需要整合多个组件——包括 LLM 调用、工作流编排、外部工具调用、记忆管理、RAG（检索增强生成）等——这对开发者的技术能力提出了较高要求，也使得 AI 应用的开发效率受到制约。

当前市场上虽然已有一些工作流编排工具（如 LangFlow、ComfyUI、Dify 等），但在以下方面仍存在明显不足：

- **缺乏深度 LLM 集成**：多数工具仅支持简单的 API 调用，缺乏对 Agent 推理链、多模型协作、工具调用等高级能力的产品化支持；
- **可视化与灵活性的平衡欠佳**：部分工具要么过于简陋、缺乏可视化编辑器，要么过度封装导致灵活性不足；
- **实时性与可观测性薄弱**：工作流执行过程中的状态监控、日志追踪、异常告警等可观测性能力普遍缺失；
- **多租户与团队协作能力不足**：难以满足企业级团队协作与多项目管理的需求。

### 1.1.2　设计目标

本项目旨在设计并实现一个名为 **Flowly** 的 AI Agent 工作流编排平台，核心设计目标如下：

1. **可视化工作流编辑器**：提供基于拖拽的可视化编辑器，使非技术用户也能构建复杂工作流；
2. **多模型 LLM 网关**：统一接入 OpenAI GPT、Anthropic Claude 系列模型；
3. **AI Agent 生命周期管理**：支持 Agent 的创建、配置、调试和部署；
4. **自然语言生成工作流**：用户以自然语言描述需求，系统自动生成工作流草图；
5. **实时执行监控**：通过 WebSocket 实现执行过程的实时推送；
6. **RAG 知识增强**：提供完整的检索增强生成管线；
7. **多租户与团队协作**：支持团队成员权限管理与工作流共享。

### 1.1.3　设计约束与可行性分析

- **技术栈选型**：前端 Vue 3 + Vite + Element Plus + Vue Flow，后端 Django 5 + DRF，均为业界主流框架；
- **开发时间**：课程时间为 2026.4.20—2026.4.30（约 10 天），优先实现核心功能；
- **成本约束**：优先使用开源技术栈，开发测试成本可控。

### 2.4.4　关键算法设计

**LLM 网关路由算法（策略模式）：**

LLM 网关采用策略模式设计，通过统一的接口抽象不同 LLM 提供商的差异：

```python
# 网关路由核心逻辑
class LLMGatewayFactory:
    _providers: dict[str, type[LLMProvider]] = {}

    @classmethod
    def register(cls, provider_name: str, provider_class: type[LLMProvider]):
        cls._providers[provider_name] = provider_class

    @classmethod
    def get_provider(cls, provider_name: str, **kwargs) -> LLMProvider:
        provider_class = cls._providers.get(provider_name)
        if not provider_class:
            raise ValueError(f"未知的 LLM 提供商: {provider_name}")
        return provider_class(**kwargs)

    @classmethod
    def chat(cls, provider_name: str, messages: list[dict], **kwargs) -> LLMResponse:
        provider = cls.get_provider(provider_name, **kwargs)
        return provider.chat(messages, **kwargs)
```

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Iterator

@dataclass
class LLMResponse:
    content: str
    model: str
    usage: dict  # {prompt_tokens, completion_tokens, total_tokens}
    finish_reason: str
    raw_response: dict  # 原始响应

@dataclass
class StreamChunk:
    delta: str  # 增量内容
    index: int  # chunk 序号
    finished: bool  # 是否完成

class LLMProvider(ABC):
    """LLM 提供商抽象基类"""

    def __init__(self, api_key: str, base_url: str = None, **kwargs):
        self.api_key = api_key
        self.base_url = base_url

    @abstractmethod
    def chat(self, messages: list[dict], **kwargs) -> LLMResponse:
        """非流式对话"""
        pass

    @abstractmethod
    def stream_chat(self, messages: list[dict], **kwargs) -> Iterator[StreamChunk]:
        """流式对话"""
        pass

    @abstractmethod
    def get_model_list(self) -> list[str]:
        """获取支持的模型列表"""
        pass

    @abstractmethod
    def validate_api_key(self) -> bool:
        """验证 API Key 是否有效"""
        pass
```

from openai import OpenAI

class OpenAIProvider(LLMProvider):

            messages=messages,
            temperature=temperature,
            max_tokens=max_tokens,
            **kwargs

            model=response.model,
            usage={

                'completion_tokens': response.usage.completion_tokens,
                'total_tokens': response.usage.total_tokens,
            },
            finish_reason=response.choices[0].finish_reason,
            raw_response=response.model_dump()
        )

    def stream_chat(self, messages: list[dict], model: str = "gpt-4",
                    **kwargs) -> Iterator[StreamChunk]:
        stream = self.client.chat.completions.create(
            model=model, messages=messages, stream=True, **kwargs
        )
        for i, chunk in enumerate(stream):
            delta = chunk.choices[0].delta.content or ""
            finished = chunk.choices[0].finish_reason is not None
            yield StreamChunk(delta=delta, index=i, finished=finished)

    def get_model_list(self) -> list[str]:
        return ["gpt-4", "gpt-4-turbo", "gpt-3.5-turbo"]

    def validate_api_key(self) -> bool:
        try:
            self.client.models.list()
            return True
        except Exception:
            return False

# gateway/services.py
class LLMGateway:
    """统一 LLM 网关服务"""

    def __init__(self, tenant_id: int):
        self.tenant_id = tenant_id
        self.registry = LLMProviderRegistry()

    def _get_provider_for_model(self, model: str) -> tuple[LLMProvider, str]:
        """根据模型名确定提供商"""
        provider_name = self.registry.get_provider_for_model(model)
        credentials = self._get_credentials(provider_name)
        return self.registry.get_provider(provider_name, credentials)

    def chat(self, model: str, messages: list[dict], **kwargs) -> LLMResponse:
        provider = self._get_provider_for_model(model)[0]
        return provider.chat(messages, model=model, **kwargs)

    def stream_chat(self, model: str, messages: list[dict], **kwargs) -> Iterator[StreamChunk]:
        provider = self._get_provider_for_model(model)[0]
        return provider.stream_chat(messages, model=model, **kwargs)

    def _get_credentials(self, provider_name: str) -> dict:
        """从数据库获取加密的凭证并解密"""
        credential = APICredential.objects.filter(
            tenant_id=self.tenant_id,
            provider__name=provider_name,
            is_active=True
        ).first()
        if not credential:
            raise ValueError(f"租户 {self.tenant_id} 未配置 {provider_name} 的 API 凭证")
        return {'api_key': decrypt_api_key(credential.encrypted_key, credential.iv)}

# agents/engine.py
class AgentEngine:
    """AI Agent 执行引擎"""

    def __init__(self, agent: Agent, user_id: int):
        self.agent = agent
        self.user_id = user_id
        self.llm_gateway = LLMGateway(tenant_id=agent.tenant_id)
        self.tool_executor = ToolExecutor(agent.tools.all())

    def chat(self, message: str, session_id: str = None,
             stream: bool = True) -> dict | Iterator[StreamChunk]:
        """处理 Agent 对话"""
        # 1. 获取或创建会话
        conversation = self._get_or_create_conversation(session_id)

        # 2. 构建消息列表（包含系统提示词和历史）
        messages = self._build_messages(conversation, message)

        # 3. 获取 RAG 上下文（如绑定了知识库）
        if self.agent.vector_store:
            rag_context = self._get_rag_context(message)
            messages = self._inject_rag_context(messages, rag_context)

        # 4. 调用 LLM（流式或非流式）
        if stream:
            return self._stream_chat(messages, conversation)
        else:
            return self._non_stream_chat(messages, conversation)

    def _build_messages(self, conversation: AgentConversation, new_message: str) -> list[dict]:
        messages = [
            {"role": "system", "content": self.agent.system_prompt}
        ]
        # 添加历史消息（限制最近 N 条，避免 token 超出限制）
        history = conversation.messages[-20:]  # 最近 20 条
        for msg in history:
            messages.append({"role": msg["role"], "content": msg["content"]})
        messages.append({"role": "user", "content": new_message})
        return messages

    def _stream_chat(self, messages: list[dict], conversation: AgentConversation) -> Iterator[StreamChunk]:
        for chunk in self.llm_gateway.stream_chat(
            model=self.agent.model,
            messages=messages,
            temperature=self.agent.temperature,
            max_tokens=self.agent.max_tokens,
        ):
            yield chunk
```

### 3.2.4　模块四：API 凭证安全管理

API 凭证采用 AES-256-GCM 加密存储，确保安全性：

```python
# gateway/security.py
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os, base64

class CredentialManager:
    """API 凭证加密管理"""

    MASTER_KEY = os.environ['CREDENTIAL_MASTER_KEY']  # 32 字节主密钥

    @staticmethod
    def encrypt(plaintext: str) -> tuple[str, str]:
        """加密 API Key，返回 (密文, IV)"""
        iv = os.urandom(12)  # 96 位 IV
        aesgcm = AESGCM(CredentialManager.MASTER_KEY.encode())
        ciphertext = aesgcm.encrypt(iv, plaintext.encode(), None)
        return base64.b64encode(ciphertext).decode(), base64.b64encode(iv).decode()

    @staticmethod
    def decrypt(ciphertext: str, iv: str) -> str:
        """解密 API Key"""
        aesgcm = AESGCM(CredentialManager.MASTER_KEY.encode())
        ct = base64.b64decode(ciphertext)
        iv_bytes = base64.b64decode(iv)
        return aesgcm.decrypt(iv_bytes, ct, None).decode()
```

## 4.4　课程心得

本次课程设计让我对大语言模型的应用开发有了更深的理解。在设计 LLM 网关时，我深刻体会到了"接口抽象"的重要性——虽然 OpenAI 和 Anthropic 的 API 非常相似，但仍然存在参数命名、响应结构等方面的差异。通过策略模式将这些差异封装在各自的 Provider 中，上层调用方无需关心底层细节，可以随时切换模型而无需修改业务代码。
