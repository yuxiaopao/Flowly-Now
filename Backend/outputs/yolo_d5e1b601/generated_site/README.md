## Quick Start

### Local Development

1. **Install backend dependencies**:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. **Configure environment**:
   ```bash
   cp ../.env.example .env
   # Edit .env with your model path
   ```

3. **Start backend**:
   ```bash
   python app.py
   ```

4. **Install frontend dependencies** (in project root):
   ```bash
   cd frontend
   npm install
   ```

5. **Start frontend**:
   ```bash
   npm run dev
   ```

### Docker Deployment

1. **Build and run with Docker Compose**:
   ```bash
   docker-compose up --build
   ```

2. Access the application:
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:5000

## API Documentation

### POST /predict

Upload an image or data for prediction.

**Request**:
- Content-Type: `multipart/form-data`
- Body: `file` - The file to predict

**Response**:
```json
{"boxes": [], "model_info": {}, "latency_ms": 12.5}
```

### GET /health

Health check endpoint.

**Response**:
```json
{"status": "healthy", "model_loaded": true}
```

## Development Notes

- Ensure your trained model file is placed in the `backend/` directory
- Update `LABELS` in `.env` to match your model's classes
- The backend expects a model file compatible with ultralytics
